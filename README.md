# Revisão para Provas

Plataforma estática de revisão (HTML/CSS/JS, sem build) para três disciplinas:
Fundamentos de IA, Projeto de Software e Sistemas Digitais e Microprocessadores.

- `index.html`: menu principal
- `revisao.html?d=fia|ps|sdm`: revisão por tópicos
- `atividades.html?d=fia|ps|sdm`: atividades resolvidas
- Conteúdo em `conteudo/<sigla>/` (formato em `conteudo/FORMATO.md`)

Publicação: GitHub Pages a partir da raiz da branch `main`.
